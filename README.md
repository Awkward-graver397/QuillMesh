## 📝 Your First Document

Let's walk through creating your first Markdown document in QuillMesh:

1. **Open QuillMesh** – Double-click the app icon.
2. **Start a new document** – Click "File" in the top menu, then "New Document."
3. **Write your content** – Type freely. Try these examples:
   - Type `# Hello World` and press Enter. That creates a big title.
   - Type `**This is bold**` – the text will turn bold.
   - Type `- First item` and press Enter. That creates a bulleted list.

5. **Save your document** – Click "File" then "Save As." Give it a name and choose where to store it. Your file will be saved with a `.md` extension.

## 📚 Learning Markdown

Markdown might sound complicated, but it's simply a set of easy-to-remember symbols. Here's a quick cheat sheet:

- `#` – Big heading
- `##` – Medium heading
- `###` – Small heading
- `**bold**` – Bold text
- `*italic*` – Italic text
- `-` – Bullet point
- `1.` – Numbered list
- `[text](link)` – Add a hyperlink
- `![description](image.jpg)` – Add an image

That's all you need to know to get started. The best way to learn is by experimenting.
